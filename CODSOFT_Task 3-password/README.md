# 🔐 Password Generator

## 📌 Project Description

A **Password Generator** is a useful Python application that generates random passwords for users.

This project allows users to specify the desired password length and choose the password complexity. The program then generates and displays a random password.

## 🎯 Objective

The main objective of this project is to create a simple password generator using Python and understand concepts such as:

* User input
* Strings
* Random character selection
* Loops
* Conditional statements
* Python modules

## ✨ Features

* Specify password length
* Generate random passwords
* Choose password complexity
* Generate passwords using letters
* Generate passwords using numbers
* Generate passwords using special characters
* Display the generated password

## 🔑 Password Complexity

The application provides three options:

### 1. Letters Only

Uses uppercase and lowercase letters.

Example:

```text
AbCdEfGhIjKl
```

### 2. Letters + Numbers

Uses letters and numbers.

Example:

```text
Ab7K92xLm5Qp
```
